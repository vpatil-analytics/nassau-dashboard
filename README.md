📌 Project Overview

This project is an interactive E-Commerce Sales Dashboard built using Python and Streamlit. It provides real-time insights into sales performance, product trends, regional distribution, and operational efficiency.

Streamlit allows developers to quickly build and share data apps using only Python, without needing frontend frameworks .

🎯 Objectives
Analyze overall sales performance
Identify top-performing products and regions
Track operational efficiency (shipping time)
Enable dynamic filtering for decision-making
🗂️ Dataset Description

The dataset includes:

Order Details: order_id, order_date, ship_date
Product Info: product_name, division
Location: region, city, state
Metrics: sales, units
